# Habit & Study Tracker

A Java console application that helps users manage daily habits and study goals.

## Features

### Version 1
- Add habits
- Add study topics
- View today's schedule
- Mark habits as completed
- Mark study topics as completed
- Delete habits
- Delete study topics
- Menu-driven interface
- Exception handling for invalid input

### Version 2
- Improved project structure using Object-Oriented Programming
- Separate classes for:
  - User
  - Habit
  - StudyTopic
  - Tracker
- Better code organization
- Easier to maintain and extend

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Collections (ArrayList)
- Exception Handling
- Git
- GitHub

## Future Improvements (Version 3)

- Multiple user support
- File storage
- Login system
- Database integration
- User authentication
- Better UI
- Statistics and progress tracking
